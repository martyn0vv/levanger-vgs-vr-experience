# Исходные сканы

Крупные оригиналы сканов храните здесь локально, вне Unity `Assets`. Эта папка исключена из Git кроме данного файла. Нужна отдельная резервная копия; Git её не заменяет.

В рабочий Unity-проект добавляйте подготовленные модели, текстуры и их `.meta`. Перед первым большим импортом выберите хранилище бинарных ассетов и при необходимости настройте Git LFS; в этом стартовом наборе LFS не включён.
