## Масштаб, контроллеры, движение

- [ ] После запуска видно окружение и оба контроллера. Повороты головы отслеживаются без смещения мира.
- [ ] Верх пола совпадает с виртуальным уровнем пола; высота глаз берётся из Floor Level tracking, без добавленных вручную 1.7 м.
- [ ] Метровый ориентир соответствует измерению в реальном пространстве.
- [ ] Стартовый режим — teleport; наведение и отпускание стика переносят в каждую из трёх заданных точек на полу.
- [ ] Стены, подиум, куб и остальной пол не являются целями телепорта. Дуга блокируется препятствиями; точки не пересекаются с ними, капсула после посадки имеет свободное место.
- [ ] Отпустить оба стика, нажать B: доступно smooth movement; повторное нажатие возвращает teleport.
- [ ] Snap turn поворачивает на 30° в обоих режимах; плавный поворот не включён одновременно.
- [ ] Smooth movement останавливается у стен/подиума; персонаж стоит на полу и не проваливается.
- [ ] После teleport к каждой точке можно снова передвигаться, без зависания и дрожания.
- [ ] Выйти из приложения и открыть снова: возвращаются teleport и snap 30°.

Физическое движение головы и тела внутри guardian — отдельный случай: коллайдер персонажа не гарантирует блокировку реального наклона сквозь виртуальную стену. Для v0.1 проверяем столкновения искусственного перемещения; решение для проникновения головы добавляем отдельно при необходимости.

## Тестовый предмет

- [ ] Подойти или телепортироваться к подиуму, поднести контроллер к кубу, зажать grip: куб следует за рукой.
- [ ] Отпустить grip: предмет падает и остаётся на подиуме или полу.
- [ ] Повторить каждой рукой, поднять с пола, бросить умеренно в стену: нет проваливания и выброса с огромной скоростью.
- [ ] Куб не меняет масштаб при захвате. В Transform размер соответствует 20 см.

## Производительность

- [ ] Прогнать 10 минут непосредственно на шлеме, включая движение и grab.
- [ ] Записать CPU/GPU frame time и пропущенные кадры в OVR Metrics Tool или Profiler; не судить по FPS редактора на Mac.
- [ ] При выбранных 72 Гц целевой бюджет кадра — 13.89 мс, при 90 Гц — 11.11 мс; оценить CPU и GPU отдельно и оставить запас для скана.
- [ ] Нет заметного роста памяти, регулярных GC-пауз и сильного ухудшения после прогрева.

Готовность запрошенного APK фиксируется после успешного завершения сборки. Полная приёмка VR v0.1 потребует отложенных проверок на Quest. Если минимальная сцена не проходит аппаратный тест, сначала исправляем rig/settings, затем переходим к скану.
